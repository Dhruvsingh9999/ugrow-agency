DROP YOUR VIDEO FILES IN THIS FOLDER
====================================

Two sets are needed. Filenames must be exact and lowercase.


1) THE REEL MARQUEE  (index.html + the reel strip)
--------------------------------------------------
    reel-01.mp4   reel-02.mp4   reel-03.mp4   reel-04.mp4   reel-05.mp4
    reel-06.mp4   reel-07.mp4   reel-08.mp4   reel-09.mp4   reel-10.mp4

Orientation alternates, so this matters:

    ODD  (01,03,05,07,09) = VERTICAL   9:16   (1080 x 1920)
    EVEN (02,04,06,08,10) = HORIZONTAL 16:9   (1920 x 1080)


2) THE "AFTER" CLIPS  (work.html, Before -> After section)
-----------------------------------------------------------
    work-01.mp4   work-02.mp4   work-03.mp4   work-04.mp4

    All four are VERTICAL 4:5  (1080 x 1350)

Each sits beside a "Before" still. work-01 pairs with the first row,
work-02 the second, and so on.


EXPORT SETTINGS
---------------
    H.264 / MP4, AAC audio, 30fps
    Keep each file UNDER 3 MB. Target 2 MB.
    These autoplay on scroll - a 20 MB clip will stall the page on mobile,
    which is where most of your traffic will be.

    Handbrake preset that works: "Web > Vimeo YouTube 720p30", RF 26.


Until you upload them the still poster images show instead, so neither page
ever looks broken. Nothing else needs changing - upload and refresh.
